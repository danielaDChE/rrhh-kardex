# Prototipo demostrativo - Sistema Integrado de Administración de Personal SEDEGES

## Objetivo
Mostrar el alcance funcional propuesto sin instalar servidor. La idea central es **registrar una vez, reutilizar, aprobar, generar documentos y conservar historial**.

## Tecnologías de esta demostración
- HTML5
- CSS3
- JavaScript
- Bootstrap / Gentelella (base visual)
- Chart.js
- localStorage para simular persistencia

## Módulos
1. Administración y Seguridad
2. Kardex de Personal
3. Recursos Humanos / Gestión de Memorándums y POAI
4. Control de Personal
5. Planillas y Remuneraciones
6. Servidor Público
7. Reportes y Auditoría

## Importante
Los datos personales, CI, ítems, sueldos y movimientos son **ficticios** y solo sirven para demostrar el funcionamiento.

El prototipo no digitaliza hojas como pantallas independientes. Los documentos (Ficha Personal, Hoja de Vida, Acta, Memorándum, Certificado, etc.) se generan a partir de información ya registrada.

## POAI
La demostración incluye perfiles POAI 2026 ficticios estructurados con: formación requerida, experiencia general, experiencia específica y funciones principales. El archivo `PERFILES POAI 2026.xlsx` no estuvo disponible en el entorno de esta generación; cuando se adjunte se pueden ajustar los campos y ejemplos exactamente al formato institucional.

## Identidad visual
El prototipo intenta cargar el logo publicado en el portal oficial actual de SEDEGES desde:
https://www.sedegeslapaz.gob.bo/img/content/sedegesfoot.png
Si el equipo está sin Internet, se muestra automáticamente una marca textual local de respaldo.
